НІКА — Google Sheets / Apps Script — final v2
==============================================

ЗМІНИ ЦІЄЇ ВЕРСІЇ
1. На сторінці «Огляд підприємства» показник «Залишок безготівки на рахунку» =
   сума залишків безготівки всіх будівництв МІНУС усі безготівкові накладні витрати.

2. Excel-експорт:
   - XLSX формується в пам'яті Apps Script;
   - після натискання EXEL файл одразу завантажується на ПК;
   - Google-таблиця для експорту не створюється;
   - у Google Drive експортний файл не зберігається.

3. Telegram:
   - зміни накопичуються;
   - повідомлення надсилається через 30 хвилин після ОСТАННЬОЇ зміни;
   - якщо протягом 30 хвилин є нова зміна, відлік автоматично продовжується;
   - надсилається одне зведення з усіма накопиченими змінами;
   - враховуються зміни через застосунок та ручні редагування бізнес-аркушів
     «Стройки», «Витрати», «Накладні», «Договори», «Акти».

ВСТАНОВЛЕННЯ
1. У Google Таблиці відкрийте: Розширення → Apps Script.
2. Замініть вміст Code.gs на файл Code.gs з цього пакета.
3. Замініть Index.html на файл Index.html з цього пакета.
4. Збережіть проект.
5. Один раз вручну запустіть setupSheets().
   Під час першого запуску Google попросить дозволи, у тому числі на створення тригера.
6. У вкладці «Налаштування» перевірте:
      telegram_bot_token   = токен Telegram-бота
      chat_ids             = один або кілька chat_id через кому
7. Для негайної перевірки Telegram вручну запустіть testTelegramNow().
   Це лише тест; робочі повідомлення надалі йдуть через 30 хвилин після останньої зміни.
8. Запустіть testSpreadsheetConnection().
9. Запустіть testLogin().
10. Запустіть testDispatchState().
11. Після успішних тестів: Deploy → Manage deployments → Edit/New version → Deploy.

ВАЖЛИВО
- dispatch() вручну кнопкою Run не запускайте: вона отримує параметри з веб-застосунку.
- setupSheets() автоматично створює installable onEdit trigger для ручних змін у бізнес-аркушах.
- Формули будівництв, накладних, конвертації, договорів та результатів залишені як у фінальній версії,
  окрім спеціально зміненого загального показника залишку безготівки на сторінці «Огляд підприємства».
