СТРОЙФИНАНС 1.1 — приложение для учёта малого строительного предприятия
=======================================================================

Что изменено в версии 1.1
-------------------------
1. Исходные данные приведены в соответствие с обновлённой книгой Excel:
   • добавлены прямые наличные расходы по обеим стройкам;
   • добавлены выплаты бригадам и прорабу;
   • добавлены наличные накладные расходы на 8 000 грн;
   • автоматически пересчитаны накладные и чистая прибыль.
2. Добавлен импорт Excel. Теперь обновлённую книгу можно загрузить прямо в
   приложение через «Настройки» → «Загрузить Excel».
3. Импорт поддерживает как исходный шаблон, так и Excel, экспортированный
   из приложения.
4. При редактировании сохраняются нестандартные категории, найденные в книге.

Что умеет приложение
--------------------
1. Добавлять неограниченное количество строек.
2. Вводить по каждой стройке:
   • приходы;
   • безналичные расходы;
   • основные средства;
   • прямые наличные расходы по категориям;
   • заработную плату.
3. Хранить общие накладные расходы в одном разделе «Накладні».
4. Автоматически распределять общие накладные между стройками пропорционально обороту.
5. Автоматически пересчитывать сводный раздел «Результат».
6. Экспортировать Excel-книгу:
   • отдельный лист для каждой стройки;
   • только один лист «Накладні»;
   • один динамический лист «Результат»;
   • формулы создаются автоматически при каждом экспорте.
7. Импортировать данные из книг Excel поддерживаемой структуры.
8. Создавать и восстанавливать резервную копию JSON.

Запуск в Windows
----------------
1. Распакуйте папку «СтройФинанс» в удобное место.
2. Дважды нажмите start_windows.bat.
3. Откроется браузер с приложением.
4. Не закрывайте чёрное окно, пока работаете с приложением.

Требования: Python 3.10 или новее. Дополнительные библиотеки не нужны.

Запуск на macOS / Linux
-----------------------
Откройте терминал в папке приложения и выполните:
  ./start_linux_mac.sh

Данные и обновление существующей установки
------------------------------------------
Рабочая база создаётся автоматически в папке data/business.db.
При первом запуске новой папки загружаются данные из обновлённой таблицы.

Если вы заменяете файлы в уже используемой папке и там существует
business.db, приложение сохранит прежнюю базу. Для переноса изменений:
1. Сначала скачайте резервную копию JSON.
2. Откройте «Настройки».
3. Нажмите «Загрузить Excel».
4. Выберите обновлённую книгу. Текущие данные будут заменены данными из неё.

Формулы
-------
Ставка конвертации по умолчанию: 14%.

Расход на конвертацию стройки =
  (оборот − безналичные расходы) × ставка конвертации

Общие накладные к распределению =
  безналичные накладные + наличные накладные − корректировка конвертации

Доля накладных стройки =
  общие накладные × оборот стройки / общий оборот

Чистая прибыль =
  оборот − безналичные расходы − расход на конвертацию
  − прямые наличные расходы − доля общих накладных

Примечание
----------
Excel ограничивает название листа 31 символом и запрещает символы \ / * ? : [ ].
При экспорте приложение автоматически делает безопасные и уникальные названия листов,
при этом полное название стройки сохраняется внутри листа и в сводной таблице.
